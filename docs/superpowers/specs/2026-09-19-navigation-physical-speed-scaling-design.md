# 导航物理速度最小改造设计

## 目标

允许导航端发送 `vx/vy/vw` 各 `±5.0` 的物理速度目标，并修正当前导航速度到归一化底盘命令之间的比例失真，不修改双板 CAN 帧格式。

## 行为

- `vx_mps`、`vy_mps` 的合法范围调整为 `[-5.0, 5.0] m/s`。
- `vw_rad_s` 的合法范围调整为 `[-5.0, 5.0] rad/s`。
- 根据当前底盘参数计算理论最大线速度：`0.075 m * 52 rad/s = 3.9 m/s`。
- 根据轮心距离计算理论最大角速度：`3.9 m/s / 0.245 m = 15.918367 rad/s`。
- 导航命令转换为：`x=vx/3.9`、`y=vy/3.9`、`z=vw/15.918367`。
- 双板 CAN 继续将 `x/y/z` 限制到 `[-1,1]`；因此 `5 m/s` 平移目标会按当前底盘理论能力饱和，而 `5 rad/s` 角速度目标可保持物理比例。

## 范围

- 修改 `Modules/NavHostLink/NavHostLink.hpp` 的合法性边界和归一化常量。
- 更新 `Modules/NavHostLink/tests/nav_host_link_test.cpp` 与配置静态回归测试。
- 不修改 `CMD`、双板 CAN ABI、底盘运动学参数或未被当前云台配置使用的旧 `HostData` 模块。

## 验收标准

- 三个速度分量绝对值等于 `5.0` 时合法，任一分量超过 `5.0` 时整包拒绝。
- `1.0 m/s` 转换为约 `0.256410`，由底盘还原后约为 `1.0 m/s`。
- `5.0 rad/s` 转换为约 `0.314103`，由底盘还原后约为 `5.0 rad/s`。
- `ChassisTarget` 仍为 45 字节，双板 CAN 帧布局不变。
